# Авангард и вкус

Интерактивный лонгрид: авангард.

Чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Структура

```
index.html      разметка всех экранов
css/style.css   стили и цветовые токены (светлая и тёмная тема)
js/main.js      ползунки, стекло, сцены со скроллом, таймлайн, полка
img/            вырезанные картинки (корабль, гора бюстов, бюсты, картина)
```
