# Авангард и вкус

Интерактивный лонгрид: мейнстрим, отторжение и право на собственный вкус.

Чистые HTML, CSS и JavaScript, без сборки и зависимостей. Единственное внешнее подключение — шрифт Manrope с Google Fonts.

## Структура

```
index.html      разметка всех экранов
css/style.css   стили и цветовые токены (светлая и тёмная тема)
js/main.js      ползунки, стекло, сцены со скроллом, таймлайн, полка
img/            вырезанные картинки (корабль, гора бюстов, бюсты, картина)
```

## Запуск локально

Откройте `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него всё содержимое этой папки (index.html должен лежать в корне репозитория).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
